# Commodore 8-bit 
This directory contains disk images for Commodore 64, 128, 16/116/Plus/4 computers. Sector images are in D64 format, nibble streams are in G64 format so as to capture copy-protected disks correctly. Wherever a filesystem is not readable with Applesauce, files will not be included. If I was unable to get a good disk read, the original SCP file is included with a note detailing the missing data/read errors.
## Notes: 
Since I do not currently have a floppy drive that can read the back side of a flippy disk which does not have the second index hole punched, most images in this directory contain only the first side. Images are suffixed `_Sx` to indicate which side of the disk was read.
